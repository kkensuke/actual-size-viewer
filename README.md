# Actual Size Calibration Tool

A simple web tool to display objects at their actual physical size on any screen, complete with an on-screen ruler and calibration feature.

🌐 **[Web App](https://kkensuke.github.io/actual-size-viewer/)**

## ✨ Features
* **Accurate Real Size Display:** Displays any specified width and height at their exact physical dimensions on your monitor.
* **Easy Calibration:** Uses a standard credit card (8.56cm × 5.398cm) to easily calibrate the screen's pixel density (PPI).
* **On-Screen Ruler:** A fixed vertical ruler on the left side of the screen that dynamically scales with your calibration settings.
* **Bilingual Support (i18n):** Seamlessly switch between English and Japanese with a single click.
* **Zero Dependencies:** Built with pure HTML, CSS, and Vanilla JavaScript. No frameworks, build tools, or external libraries required.

## 🚀 How to Use
1. Open the [Web App](https://kkensuke.github.io/actual-size-viewer/).
2. **Calibrate:** Place a standard credit card or driver's license against the "Reference Card" box on the screen. Adjust the slider until the on-screen box perfectly matches the physical card.
3. **Measure/Display:** Once calibrated, the left ruler becomes an accurate 1mm-scale physical ruler. You can also enter any custom width and height to visualize the exact real-world size of an object on your display.
